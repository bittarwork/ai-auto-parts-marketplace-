1) GOAL OF THIS PLAN
================================================================================

Convert the existing MERN marketplace from "Chinese combustion-car parts"
into an "Electric Vehicle (EV) spare parts store" without rebuilding the
project from scratch.

The existing architecture already matches the study:
- MongoDB + Express + React + Node.js
- JWT authentication
- OpenAI natural language search
- Vehicle-to-part compatibility
- Cart, checkout, orders
- Admin dashboard

What must change is the DOMAIN, CONTENT, BRANDING, and a few data fields.
What should NOT be done first: rewrite the stack, add Stripe, Cloudinary,
Atlas Search, Gemini, or Redux just because they appear in the proposal table.

9) RISKS AND HOW TO AVOID THEM
================================================================================

Risk 1: Seed still contains combustion parts
Fix: rewrite seed.js completely, then search the repo for Chery, Tiggo,
oil filter, spark plug, timing belt.

Risk 2: Enums updated in one file but not others
Fix: one shared brand list in backend, then update frontend lists to match.

Risk 3: NLP works but returns zero products
Fix: seed products must use the same brand/model strings as the NLP output
(Tesla / Model 3, not "tesla model-3").

Risk 4: Study text claims Stripe / Atlas / Cloudinary / Redux
Fix: either implement or edit the study. Do not claim unused tools.

Risk 5: Checkout totals ignore Settings
Fix: Phase 2 must read Settings in cart and order creation.

Risk 6: Register allows administrator role
Fix: force role=customer on public register.

Risk 7: Spending weeks on deployment/payments before the catalog is EV
Fix: finish Phase 1 first. The committee will judge the idea by search + data.
